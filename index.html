Firebase 與 GitHub Pages 設定

如何放上 GitHub Pages 免費玩？
  1. 在 GitHub 建立一個公開 Repository (例如: pictomania)。
  2. 將本檔案命名為 index.html 上傳。
  3. 到 Settings > Pages，Source 選 Deploy from a branch (main) 儲存。
  4. 數秒後獲取網址即可分享給所有朋友的手機！

若要跨手機連線，請貼上你自己在 Firebase Console 建立的 Config：
